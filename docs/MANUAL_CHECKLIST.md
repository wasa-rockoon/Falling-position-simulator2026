# 手動確認チェックリスト

## 基本表示

- `node cors-proxy.js` 後、`http://localhost:3100/` が開く。
- `http://localhost:3100/__server-info` の静的配信元がこのプロジェクトを指す。
- ローカルAPIを使う場合はTawhiriの8000番ポートを先に起動する。予測だけが `502` の場合はフロントではなく転送先の起動状態を確認する。
- 地図、サイドバー、テーマ切替、タブ、モバイル表示が操作できる。
- Consoleに未処理例外やローカル資産の404がない。

## 通常予測・愛媛モード

- APIをSondeHubまたは起動済みローカルTawhiriに合わせる。
- 通常予測が地図・高度チャート・風チャートへ表示される。
- 通常予測開始時に `Illegal invocation` や `requestContext is not defined` が表示されない。
- 愛媛モード13条件が完了し、範囲・比較表・CSV/KMLが出力できる。
- 実行中に別機能を開いてもAPI接続先が勝手に変わらない。

## 自動探索

- 開始前に候補数、最大API呼出数、概算時間が表示される。
- 高速モードでは粗探索不合格を除外する。
- 全件精査モードでは粗探索不合格も13条件評価へ進む。
- ランキングモードでは除外せず見込み順に評価する。
- 海上率は下限以上、他の上限制約は上限以下で合格する。
- 「現在の候補完了後に中断」で次候補へ進まず、再開できる。
- 完了時にCSVが自動保存され、結果欄の「CSV出力」から追加保存もできる。
- 再読込後も保存ジョブを再開できる。

## 保存・履歴

- 通常フォームの前回値とプリセットが再読込後も復元される。
- 保存した放球地点が既存Cookieから読み込める。
- 愛媛モードの履歴が直近10件を上限として表示される。
- 自動探索・不確実性解析の完了済み結果と進行中ジョブを混同しない。

## 気球ガス計算

- 初期値でガス量約9.4565m³、断熱補正ボンベ本数約1.5753本になる。
- 1200g気球は係数未定義として明示される。
- 上昇速度と推奨破裂高度を予測フォームへ反映できる。
- 6種類の破裂高度推定と、ボンベ不足警告が表示される。

## 不確実性解析

- 解析画面でJSTの日付・時刻を設定でき、「SETTINGSの日時を読込」で現在設定を反映できる。
- 地点数に応じた最小/最大サンプル、HTTP試行上限、概算時間が表示される。
- Sobol、Latin Hypercube、モンテカルロと正規/Weibullを選択できる。
- HTTP再試行を含め、設定した試行上限を超えない。
- 海上率95%信頼区間、平均着地点、95%確率楕円（長軸×短軸）が表示される。
- 「地図で確認」または結果行から、着地点・平均点・95%楕円を表示でき、密度50%・80%・95%等高線も別レイヤーで重ねられる。
- 現在のAPI呼出完了後に中断し、再読込後も再開できる。
- CSVを出力できる。

## PWA・オフライン

- 192px/512pxのアプリアイコンでインストールできる。
- 一度オンラインで開いた後、DevToolsをOfflineにして再読込しても画面が起動する。
- オフライン時、新しいAPI予測は明確に失敗するが画面は操作可能なままである。
- 一度表示した地図タイルはオフラインでも表示される。
- Service Worker更新時に通知が出て「今すぐ更新」で1回だけ再読込される。
